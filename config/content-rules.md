# Content-Rules – Themen-Routing (F3)

Regeln in natürlicher Sprache. Claude wendet sie bei JEDEM Verteilvorschlag an.
Das Ergebnis ist immer ein VORSCHLAG – Bernd wählt per Zuruf an/ab.

## Start-Regelwerk

- Finanzen / Business / Unternehmertum → LinkedIn (text) + X.
  Kein Instagram, kein Threads, kein TikTok.
- Vater sein / Beziehung / Persönliches → Instagram (video) + TikTok + Facebook + Threads.
  LinkedIn nur, wenn es einen klaren Business-/Leadership-Winkel gibt.
- Gesundheit / Longevity / Sport → alle Plattformen (inkl. TikTok).
- Spirituelles → nur, wenn praktisch übersetzt (kein Esoterik-Vokabular),
  dann Instagram + Threads.

## Generelle Regeln

- TikTok nur bei Format video – gibt es kein Video, fällt TikTok automatisch
  aus dem Vorschlag.
- Facebook läuft via Meta Auto-Share (nur wenn Instagram aktiv ist) und wird
  in der Matrix mit "—" markiert.

## Lernschleife

Wenn Bernd wiederholt dieselbe Korrektur macht, schlägt Claude vor, sie hier
als neue Regel festzuschreiben – nur mit Zustimmung.

### Gelernte Regeln (wächst mit der Zeit)

_Noch leer._
